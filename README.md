# אפליקציית מדידות (app/)

## מה יש בתיקייה
- **`index.html`** — כל האפליקציה: מסך פתיחה (מדידה חדשה / המשך / השלמה), מסך עבודה עם ציור על קנבס
  (עט, קווי קיר עם יישור והצמדה, אותיות קיר אוטומטיות, חותמות אלמנטים, כלי `H=`, מצלמה לקיר),
  מסך "ההגדרות שלי" (מתג לכל כלי ולכל הערה R1–R8), והמסך "סיים ושלח" (ייצוא).
  קובץ אחד, בלי שרת, בלי תלות חיצונית מלבד גופן Heebo מגוגל (יש נפילה לגופן מערכת אם אין רשת).
- **`manifest.webmanifest`** — מגדיר את שם האפליקציה, אייקון וצבעים לצורך "הוספה למסך הבית".
- **`sw.js`** — Service Worker: שומר עותק של הקבצים במטמון בפעם הראשונה שהדף נפתח,
  כך שהאפליקציה תעבוד גם בלי אינטרנט אחר כך.
- **`icon-192.png` / `icon-512.png`** — אייקון האפליקציה (סרגל צהוב על רקע כהה), נוצרו עם Python+PIL.
- כל נתוני המדידה נשמרים על המכשיר בלבד, ב-**IndexedDB** (`miki-measure`), ולא נשלחים לשום שרת.

## איך בודקים מקומית
צריך שרת מקומי פשוט כדי ש-service worker ו-manifest יעבדו (פתיחה ישירה של הקובץ מהדיסק `file://`
לא תפעיל Service Worker, אבל שאר האפליקציה כן תעבוד):

```
cd app
python -m http.server 8765
```

ואז לפתוח בדפדפן בטלפון/טאבלט/מחשב באותה רשת:
```
http://<כתובת-IP-של-המחשב>:8765/
```
או במחשב עצמו: `http://localhost:8765/`.

לבדיקת מצב "אופליין": לפתוח פעם אחת עם אינטרנט (כדי שה-Service Worker יירשם וישמור קבצים במטמון),
ואז לכבות רשת/Wi-Fi ולרענן — הדף אמור להיטען בכל זאת.

## הוספה למסך הבית (טלפון/טאבלט)
בכרום/סמסונג אינטרנט: תפריט ⋮ ← "הוספה למסך הבית". האייקון והשם מגיעים מ-`manifest.webmanifest`.

## מגבלות ידועות (ר' גם דוח המסירה)
- אין ייצור אוטומטי של אותיות קיר רק ל"קירות סגורים" — כל קו-קיר מקבל אות בסדר היצירה; בדיקת
  "חדר לא סגור" (R3) רצה בנפרד ומזהה קצוות פתוחים.
- שרשרת מקטעים (segments) לבדיקת R6 מוזנת כטקסט מופרד-פסיקים בחלונית הקיר, לא כקווי-משנה מצוירים.
- קואורדינטות השרטוט הן יחידות-דף חופשיות (לא בקנה-מידה מדויק לס״מ) — המספרים האמיתיים מגיעים
  מהקלדה/הכתבה ליד כל קיר/אלמנט, בדיוק כמו ברישום של מיקי היום. אין כפתור "יישור לפי מידות".
